# CodeGrid Design Intelligence Index

Purpose: a retrieval-friendly map of the CodeGrid source collection for a website-generating Claude Project.

## How to use this library
1. Treat this file as the map, not as the implementation source.
2. For a website request, first choose a small set of *patterns* from this index.
3. Retrieve/open only the relevant source projects needed to implement those patterns.
4. Combine patterns from different projects instead of reproducing one reference site.
5. Never let a reference determine the entire page structure, typography, palette, or content hierarchy.

## Diversity rule
Every generated website should be a new composition. References are a component library and motion vocabulary, not templates to copy.

## High-value technology vocabulary
- **GSAP / ScrollTrigger:** sequencing, scroll-linked motion, pinned sections, reveals, timelines.
- **Lenis:** smooth-scroll foundation and scroll feel.
- **SplitText:** kinetic typography and character/word-level transitions.
- **Flip:** layout-state transitions and rearrangements.
- **Observer:** wheel/touch/gesture-driven transitions.
- **Three.js / WebGL / shaders:** spatial scenes, distortion, displacement, CRT, particles, image manipulation.
- **Canvas / ASCII:** non-DOM visual rendering and procedural image/text treatments.
- **Matter.js:** physics-based interaction.
- **next-transition-router / similar:** route-level page transitions.

## Retrieval instruction
When a task calls for a specific effect, search by the design tag and project name. Do not retrieve the entire collection into the active context. Prefer 2–5 complementary references.
